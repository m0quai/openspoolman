# Bildverzeichnis

> Zur Gesamtübersicht: [START.md](../../START.md)

Diese Bilder gehören zum aktuellen AMSHelper-Gerätekontext.

- `pn532-v3-original.png` – vom Nutzer bereitgestellte Vorder-/Rückansicht des PN532 V3.
- `pn532-v3-anschluss-antenne-guide.png` – erstellte beschriftete Übersicht zum Modul, Anschluss und Antennenbereich.
- `pn532-v3-detail-guide.png` – erstellte Detailübersicht zum PN532.
- `esp32-s3-pinout.png` – vom Nutzer bereitgestellte Pinbelegung des konkreten ESP32-S3-Boards.
- `nanoframework-device-explorer-com8.png` – Nachweis, dass `ESP32_S3_N16_NOPSRAM @ COM8` in Visual Studio erkannt wird.
- `amshelper-project.png` – Screenshot des AMSHelper-nanoFramework-Projekts.

Nicht enthalten:
Der verworfene Vier-PN532-Schaltplan, der alle vier PN532 direkt parallel an GPIO8/GPIO9 zeigte. Dieser Plan ist technisch falsch, weil alle vier PN532 im I2C-Modus die Adresse 0x24 verwenden.
